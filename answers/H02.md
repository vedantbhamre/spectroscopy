## Measurement concept

Install a transmission NIR probe in the whey line (pathlength 1–5 mm) and a diffuse‑reflection NIR probe in the milk concentrate line (flush‑mounted to the pipe wall). Use the same spectrometer platform (e.g., FT‑NIR or diode‑array) to acquire spectra, apply chemometric calibration (PLS) against lab protein/fat measurements, and compare model performance for each interface. [S01 p.5; S01 p.17; S01 p.18]

- **Analyzer:** NIR spectrometer (FT‑NIR or DAD‑based) capable of both transmission and reflectance modes
- **Fibre link:** Standard silica fiber (low‑OD) suitable for NIR transmission
- **Probe:** Transmission probe for whey; diffuse‑reflection probe for concentrate
- **Process point:** Inline in the respective process streams (whey pipe, concentrate vat or pipe)

## Risks and uncertainty

- Insufficient transmission for whey if pathlength is too long, leading to signal loss.
- Surface sensitivity of reflection may cause variability if fat globule size changes.
- Potential fouling of probes in the concentrate stream; cleaning strategy needed.

## First feasibility experiment

1. Collect representative whey and concentrate samples covering expected protein/fat ranges.
2. Measure each sample with the transmission probe (whey) and reflection probe (concentrate) using the same NIR spectrometer.
3. Obtain reference protein and fat values from the laboratory methods.
4. Build separate PLS calibration models for each probe, validate on held‑out samples.
5. Then measure in-line or in a pilot set-up against the reference method.
6. Compare prediction errors and robustness; decide which interface meets the pilot criteria.
