## Recommendation

- **NIR (diffuse reflection)** (primary): Diffuse‑reflection NIR probes are designed for scattering media and powders, match the opaque blend, and are listed as average‑cost in the source table; they are widely used for in‑line blend potency monitoring in pharma. [S01 Table 1 (p.6); S01 p.15]
- **Raman spectroscopy** (comparison): Raman provides complementary information (symmetrical vibrations) and has been demonstrated for in‑line powder blend monitoring; it can help verify NIR models or resolve interferences. [S01 Table 1 (p.6); S01 p.15]

## Measurement concept

Insert a diffuse‑reflection NIR probe into the feed frame, collect spectra via a short‑length silica fiber to a bench‑top NIR spectrometer; optionally add a Raman probe at the same location for parallel data collection. [S01 p.15]

- **Analyzer:** Bench‑top NIR spectrometer (780–2500 nm) and Raman spectrometer (785 nm laser)
- **Fibre link:** Silica fiber (low‑OH) for NIR; silica or low‑loss fiber for Raman
- **Probe:** Diffuse‑reflection NIR probe (contact tip) and optional Raman fiber probe (785 nm excitation)
- **Process point:** Feed frame of the rotary tablet press, mounted on an existing process port

## Spectral range

NIR absorption range 780–2500 nm (overtones of C‑H, N‑H, O‑H); Raman excitation 785 nm with Raman shift recorded in cm‑1. [S01 p.10; S01 p.11]

## Risks and uncertainty

- High scattering may reduce signal‑to‑noise for NIR; probe fouling from dust requires cleaning strategy.
- Raman signal is weak; fluorescence from excipients could mask Raman bands.
- Calibration may be sensitive to particle size and bulk density variations.

## First feasibility experiment

1. Collect representative powder samples covering the expected API concentration range.
2. Build a chemometric calibration model (e.g., PLS) and validate on held‑out samples.
3. Repeat the same with Raman (if probe is added) to assess complementary performance.
4. Evaluate model robustness to particle size and flow rate variations.
5. Acquire NIR diffuse‑reflection spectra in‑line using the proposed probe; simultaneously record reference API values with the existing lab assay.

**Decision basis:** If the NIR model meets the agreed‑upon prediction error on independent samples, it will be the preferred method; Raman results will inform whether a combined approach is needed. Agree two things separately with the customer before the test: the model accuracy required against the reference method, and the alarm or action threshold applied to the measured value.
