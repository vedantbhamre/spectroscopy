## Recommendation

- **Raman spectroscopy** (comparison): Raman offers complementary vibrational information (symmetrical, non‑polar groups) and can be implemented with a contact probe; testing it will reveal whether it improves model robustness for the new matrix. [S01 p.5; S01 p.15]

## Measurement concept

Collect simultaneous NIR diffuse‑reflection spectra (existing probe) and Raman spectra (785 nm excitation probe) from the powder stream at the feed frame; use the NIR data to build a new calibration, and evaluate Raman data for added predictive power. [S01 p.15; S01 p.5]

- **Analyzer:** Existing NIR spectrometer; separate Raman spectrometer (if not already owned)
- **Fibre link:** Standard silica fiber for NIR; appropriate Raman fiber (e.g., low‑OH silica) for the Raman probe
- **Probe:** NIR diffuse‑reflection probe (existing) and Raman contact probe (785 nm excitation)
- **Process point:** Feed frame of the rotary tablet press, inserted into the powder flow

## Spectral range

NIR absorption range (≈780–2500 nm) measured in diffuse reflection; Raman excitation at 785 nm with Raman shift recorded in cm⁻¹. [S01 p.5; S01 p.10]

## Risks and uncertainty

- Matrix change may alter NIR scattering/absorption enough to require a new calibration.
- Raman signal may be weak in highly scattering powders, requiring longer integration or higher laser power.
- Probe fouling or dust buildup could affect signal stability; cleaning procedures must be defined.

## First feasibility experiment

1. Prepare a set of representative powder samples covering the expected API concentration range of the new blend.
2. Simultaneously acquire Raman spectra with a 785 nm probe on the same samples.
3. Obtain reference API concentrations using the agreed reference method (e.g., HPLC).
4. Build an NIR calibration model (e.g., PLS) and evaluate its prediction error.
5. Build a Raman‑only model and a fused NIR‑Raman model to assess any improvement.
6. Validate each model on held‑out samples not used in calibration.
7. Measure each sample with the existing NIR probe in the same in‑line geometry used for the current process.

**Decision basis:** If the NIR model meets the agreed error criteria, the existing calibration can be updated without Raman. If Raman (alone or fused) reduces error or improves robustness, consider adding Raman for production monitoring. Agree two things separately with the customer before the test: the model accuracy required against the reference method, and the alarm or action threshold applied to the measured value.
