## Risks and uncertainty

- Matrix change may shift NIR bands enough to invalidate the old calibration.
- Raman signal may be weak in highly scattering powder, requiring longer integration or higher laser power.
- Space/temperature constraints at the feed frame may limit probe installation.

## First feasibility experiment

1. Prepare a set of powder samples covering the expected API concentration range of the new blend.
2. Acquire reference API concentrations by an independent assay (e.g., HPLC).
3. Record NIR spectra with the existing probe under normal process conditions.
4. Record Raman spectra simultaneously (or sequentially) with a fiber‑optic Raman probe at the same location.
5. Build three chemometric models: NIR‑only, Raman‑only, and fused NIR‑Raman (low‑level data fusion).
6. Validate each model on held‑out samples to assess prediction error and robustness.
7. Then measure in-line or in a pilot set-up against the reference method.

**Decision basis:** If the NIR‑only model meets the agreed accuracy, the Raman addition is unnecessary; if performance degrades, the fused model will be evaluated for improvement.
